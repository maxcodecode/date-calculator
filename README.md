# Date Calculator

A free, local-only date calculator. Enter any number of days to see what date it is from today, or from a specific start date.

## What it does

- Calculate the exact date N days from today
- Change the start date to calculate from any day, past or future
- Shows the day of the week, week number, and days remaining in the target year
- Progress bar appears when a custom start date is set
- Runs entirely in the browser — no upload, no sign-up, no tracking

## Why it exists

Most date tools make you pick a date first, then count. This one starts with the number of days, because that is what contracts, medical schedules, project plans, and exam timelines actually give you.

## Tech

- Pure static HTML, CSS, and vanilla JavaScript
- No build step, no framework, no dependencies
- All calculations run locally in the browser

## Usage

Open `index.html` in any modern browser. That's it.
